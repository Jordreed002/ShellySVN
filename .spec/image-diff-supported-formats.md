# Image Diff Supported Formats

ShellySVN treats these extensions as image assets for the built-in image diff viewer:

- `png`
- `jpg`, `jpeg`
- `gif`
- `bmp`
- `webp`
- `svg`
- `ico`
- `tiff`, `tif`

Other binary or design-source formats, such as `psd`, are not opened in the built-in image diff viewer and should be reviewed through an external tool.
