## Principle

ShellySVN does not need to own every possible diff or merge experience itself. External-tool handoff remains a valid part of a serious desktop SVN workflow.

## Use external tools when

- The file type is better handled by a specialized diff viewer
- Your team already has an established merge tool
- A rollout requires compatibility with an existing review process
