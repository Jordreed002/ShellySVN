## Stable

Stable is the default update channel. It receives normal GitHub releases and ignores releases
marked as prereleases.

## Preview

Preview is opt-in under **Settings → General → Updates**. It receives newer beta and release
candidate builds as well as stable releases.

Returning to Stable never downgrades the installed application. If the installed preview is newer
than the latest stable release, ShellySVN waits until a still-newer stable version is published.

## Automatic-update support

- Windows NSIS installations update themselves after you approve the download.
- Signed and notarized macOS installations update themselves after you approve the download.
- Linux AppImage installations update themselves after you approve the download.
- Debian, RPM, tarball, portable, and development builds link to the download page instead of
  attempting a privileged or ambiguous replacement.

ShellySVN 1.1 is the updater bridge release. Builds installed before 1.1 cannot discover it
automatically, so the first updater-capable build must be installed manually. Subsequent releases
can then be delivered through the application.
