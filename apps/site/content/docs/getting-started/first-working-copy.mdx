## Recommended first-run path

Start with a repository that is representative but not enormous. The goal is to validate access, checkout behavior, update flow, and history browsing before you move bigger or older working copies into the app.

## Suggested sequence

1. Open ShellySVN.
2. Start a checkout from the repository URL.
3. If the repository is large, use sparse checkout instead of a full pull.
4. Let the working copy load, then inspect status, history, and diff surfaces.

## Early validation checklist

- Authentication prompts appear when expected.
- The working copy path opens cleanly.
- Status indicators render without blocking the rest of the app.
- History and diff views load for a known file or revision.
