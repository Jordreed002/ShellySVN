## Choose a build

ShellySVN publishes packaged desktop artifacts through GitHub Releases. Use the download page for the latest installer matrix.

- Windows: installer and portable executable when both are published
- macOS: separate Intel and Apple Silicon DMGs
- Linux: AppImage, Debian package, or tarball when available

## Before rollout

The public site still labels the product as a preview release. Treat it as an evaluation or staged rollout candidate unless your own internal validation says otherwise.

## Install flow

1. Download the artifact for your platform and architecture.
2. Launch the installer or mount the disk image.
3. Start ShellySVN and open the docs again if you need workflow help.

## What is bundled

ShellySVN release artifacts are designed around packaged binaries so users do not need to manually assemble an SVN client toolchain first.
