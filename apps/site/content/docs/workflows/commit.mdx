## Commit discipline

Treat the commit surface as the last review point before repository history changes.

## Recommended rhythm

1. Review the modified file list.
2. Inspect diffs for anything risky.
3. Confirm changelists, externals, or sparse-path details as needed.
4. Write the commit message only after the scope is genuinely clear.
